# 單字貓遠端控制說明

在 GitHub 網頁或手機 GitHub App 都能操作：打開 `word7000-app` → **Actions** → 選下面其中一個 → **Run workflow**。

> 所有會「發出去」的按鈕，預設都是 **👀 只預覽**：按下去只會列出會發出什麼，不會真的發出。
> 確認內容沒問題後，**取消勾選「只預覽」再按一次**，才會真的發出。

## 📊 版本與公告狀況（隨時都可以按，不會改變任何東西）

看大家裝了哪些版本、目前有哪些公告、有沒有強制更新。
點進那次執行，結果會整理成表格顯示在最上面。

## 📈 使用數據（隨時都可以按，不會改變任何東西）

選要看最近 7、30 或 90 天，按 **Run workflow**，點進那次執行，最上面就是整理好的表格：

- 👥 使用者：全部帳號、Apple 登入、訪客、新增、Premium 訂閱中
- 🔥 活躍：今天、昨天、7 天內、30 天內，以及每天的活躍人數
- 🔁 留存：新加入的人，隔天、第 7 天、第 30 天還有多少比例回來
- 📚 功能使用：學習、測驗、拼字、口說、掃描……各有多少人、用了幾次，以及大家選哪個字庫和級數
- 🤖 AI：各種 AI 功能用了幾次、有多少人當天把額度用完
- 💰 付費：從哪裡看到付費頁、按下購買、購買成功的人數

日期都用台灣時間。人數會分成「Apple 登入」和「訪客」：Apple 那欄最接近真人數；
已經併進 Apple 帳號的舊訪客、加入超過 7 天只打開過一天的空訪客不算進人數（資料不會刪除，報表會寫出有幾個）。

只會記「用了哪個功能幾次」，不記單字內容、答案或錄音；從 2.0.2 (6) 開始統計。
訂閱收入、試用轉換和下載量請看 App Store Connect 的「分析」與「銷售和趨勢」。

## 🍎 Apple 登入檢查（不會改變任何東西）

確認「刪除帳號時會一起把單字貓從 Apple 帳號的登入清單移除」的設定正常，並列出最近 24 小時的相關紀錄。

## ✏️ 校正單字（不用更新 App）

發現某個字的意思、例句、詞性寫錯時：

1. 保持 **👀 只預覽** 勾選。
2. ① 選模式（學英文／學中文）；② 填那個字（英文單字或中文詞都可以）。
3. ③ 選要改什麼：中文意思、補充意思、詞性、音標／拼音、例句、例句翻譯、英文單字、級數，
   或「隱藏這個字」「恢復顯示這個字」「取消這個字的所有校正」。
4. ④ 填改成什麼，按 **Run workflow**，點進去看「原本 → 改成」。
5. 沒問題就取消勾選「只預覽」再按一次。大家下次打開或回到 App 時就會套用。

- 同名的字有好幾個時，預覽會列出每個的代號，把代號填進 ② 再按一次。
- 學習紀錄不受影響；「取消校正」就會恢復原本的內容。官方字庫裡的字也能這樣校正。

## 📚 上架字庫（不用更新 App）

新字庫的內容放在 `content/banks/<代號>.json`（格式見 `content/banks/README.md`，直接請 Claude 做最快）。

1. 保持 **👀 只預覽** 勾選，① 填代號（例：`medical`），② 選「上架或更新」，按 **Run workflow**。
2. 預覽會列出字庫名稱、字數、級數、免費或 Premium，以及更新時新增／移除幾個字。
3. 沒問題就取消勾選「只預覽」再按一次。

大家下次打開或回到 App 時，「單字」頁的字庫列會多出這個字庫（Premium 字庫會有 Premium 標記，沒訂閱的人點了會看到訂閱頁）。
改了內容檔再按一次就是更新，同一個字的學習紀錄會保留。② 選「下架」就會從大家的 App 移除，正在用的人自動切回內建字庫。
「📊 版本與公告狀況」也會列出目前上架的官方字庫和生效中的校正數量。

## 📣 發公告

1. 第一次先保持 **👀 只預覽** 勾選。
2. 填 ① 中文標題、② 中文內容；有英文介面的使用者就填 ③④ 英文。
3. 需要的話再設：
   - 🔔 **推播**：重要的事才勾，會跳到大家手機的鎖定畫面。
   - 👥 **給誰看**：所有人／沒登入的訪客／登入但沒訂閱／Premium 訂閱者。
   - 🔘 **按鈕**：請大家更新／打開訂閱頁／打開網址。
   - 📱 **只給舊版本看**：例如填 `2.0.3`，只有 2.0.3 以前的版本會看到。
   - ⏳ **留幾天**：預設 7 天，0 = 直到手動下架。
4. 按 **Run workflow**，點進去看預覽內容。
5. 沒問題就再按一次 **Run workflow**，這次**取消勾選「只預覽」**。

每個人下次打開或回到 App 時，會全螢幕看到一次，要按「知道了」才會關掉。

## ⛔ 強制更新

**先確定新版已經可以下載**（TestFlight 或 App Store），再設定，不然大家會卡住。

1. 保持 **👀 只預覽** 勾選。
2. ① 填最低版本：例如 `2.0.3`；要指定建置就填 `2.0.2 (5)`（括號前有空格）。
3. ②③ 更新頁的中英文說明有預設文字，可以不改。
4. 預覽沒問題，取消勾選「只預覽」再按一次。

低於這個版本的 App 打開時，只會看到「請更新單字貓」和一顆更新按鈕，其他都不能用。
（強制更新從 2.0.2 (4) 開始有效；更舊的版本會收到同內容的公告與推播。）

## 🧹 下架公告／解除強制更新（立即生效）

選「下架所有公告」、「解除強制更新」或「兩個都做」，按 **Run workflow**。

## 🧪 測試公告：只發給自己的手機

1. 在 App「我 → 提醒 → 公告推播」，確認顯示「已登記」。
2. **長按這一行約 1 秒**，看到「這支手機已設為測試機」。
3. 發公告時「👥 給誰看」選 **只給測試手機**：公告和推播只會送到測試機，其他人完全不會看到。
4. 測完記得用「🧹 下架公告」清掉測試公告。再長按一次可以取消測試機。

## 小提醒

- 手機 GitHub App 的清單只會列出跑過的按鈕，看不到時把清單往下拉重新整理。
- 執行紀錄的標題會寫「👀 預覽」或「📣 已發出」，一眼就分得出來。
- 不想自己操作，直接跟 Claude 說要發什麼就好。
