# 單字貓（Word7000）宣傳短片

用 [Remotion](https://www.remotion.dev/) 寫成的直式（1080×1920、9:16）宣傳片，有兩個版本：

- `Full`：36 秒完整版，重點放在 AI 與客製化
- `Teaser`：12 秒試作版

兩支都以 1.2 倍慢速播放（`src/time.ts` 的 `SPEED`），讓觀眾來得及看完文字。場景仍以 30 fps 的格數撰寫，`useFrame()` 會換算成放慢後的時間軸，所以剪接點、打字和動畫一起等比例變慢，輸出依然是順暢的 30 fps。

## 使用方式

```bash
cd promo
npm install
npm run studio   # 在瀏覽器即時預覽、拖時間軸
npm run render           # 輸出 out/word7000-full-36s.mp4
npm run render:teaser    # 輸出 out/word7000-teaser-12s.mp4
npm run typecheck
```

在雲端容器或沒有下載 Chrome 的環境，可改用現有的 Chromium：

```bash
npx remotion render Full out/word7000-full-36s.mp4 --browser-executable=/opt/pw-browsers/chromium
```

## 結構

- `src/Full.tsx`：30 秒版的場景；`src/Teaser.tsx`：10 秒版的場景，開場、認識小笨貓和片尾兩版共用。兩個檔案上方的 `SCENES` 都控制每一幕的起點與長度（30 fps）。
- `src/kit.tsx`：共用的動態效果（模糊浮現、紙片貼上、蓋章、打字機）和元件，例如小笨貓對話泡泡 `CatSays`、紙條按鈕。
- `src/collage.tsx`：App「紙張拼貼」風格的素材，從 `ios/Word7000/Design/Collage.swift`（`claude/friendly-darwin-obc3r1` 分支）移植而來，包括方格紙、橫線索引卡（含紅色邊線）、紙膠帶、撕邊、網點、炭筆線圈和橡皮章。這個風格沒有陰影，靠紙張彼此重疊做出層次。
- `src/Mascot.tsx`：吉祥物「小笨貓」，從 `Mascot.swift` 逐個形狀移植成 SVG。有 idle、smug、happy、annoyed 四種表情，也會呼吸、眨眼、甩尾巴。
- `src/fonts.ts`：中文用 Noto Sans TC，英文單字用 Noto Serif（代替 App 裡的 New York 襯線字）。文案有改時要更新裡面的字表。
- `public/icon-collage.png`：拼貼風格的 App icon。`public/icon.png` 是皮革風格的 icon，`public/paper-grain.png` 是紙張紋理。

尺寸換算是「App 的 pt × 1080/402」，也就是把 402pt 寬的 iPhone 放大到 1080px。小笨貓的台詞都是 App 裡實際會出現的句子。

## 分鏡（36 秒，Full）

小笨貓就是 App 裡所有線上 AI 回答的化身，所以 AI 的段落都由牠來說。文案、按鈕和台詞都取自測試版。

| 時間 | 段落 | 畫面 |
| --- | --- | --- |
| 0.0–2.4s | 開場 | 「又在滑手機？」小笨貓：「你滑手機的時間夠背十個字了。」 |
| 2.4–4.1s | 開場 | 「認識一下，小笨貓。」嘴有點壞的 AI 單字家教，蓋「AI 家教」印章 |
| 4.1–8.3s | AI | 「不懂？叫牠講到懂。」點「叫小笨貓解說」，小笨貓說明 attend 的用法和常見搭配 |
| 8.3–11.9s | AI | 「想問什麼，直接問。」點預設問題「常見的錯誤用法是什麼？」：✗ attend to the meeting／✓ attend the meeting |
| 11.9–15.1s | AI | 「答錯了，牠說你錯在哪。」點「小笨貓，我為什麼錯？」 |
| 15.1–18.8s | AI | 「開口說，AI 幫你改。」口說教練：錄音後顯示文字，AI 給出更自然的說法和提示 |
| 18.8–22.0s | AI | 「每天一次，牠幫你抓弱點。」學習分析：做得好的地方、要加油的字、接下來幾天 |
| 22.0–25.6s | 掃描 | 「課本單字表，拍一下就好。」手寫單字表掃描後，由 Apple Intelligence 整理並存入字庫 |
| 25.6–28.7s | 客製化 | 「你的 App，你的樣子。」皮革經典切換成紙張拼貼，圖示跟著換 |
| 28.7–31.6s | 客製化 | 「每個設定，都照你的。」每日目標、學習語言、朗讀語速、單字集、學習提醒 |
| 31.6–34.1s | 提醒 | 鎖定畫面中午 12:00 的即時動態：「單字不會自己背好喔」。小笨貓：「明天同一時間，我會來找你。」 |
| 34.1–36.0s | 片尾 | 拼貼版 icon、「單字貓」、「7000 單字」印章 |

AI 的回答內容（解說、錯誤用法、分析結果、口說建議）是為影片寫的示範，App 實際會由 Claude 依當下的字和紀錄產生。

## 分鏡（12 秒，Teaser）

| 時間 | 畫面 |
| --- | --- |
| 0.0–2.4s | 「又在滑手機？」標題下畫出炭筆線，橫線紙片啪一聲貼上：「你滑手機的時間夠背十個字了。」小笨貓擺臭臉冒出來 |
| 2.4–3.8s | 方格紙背景，撕邊的蜜桃色紙片貼上，小笨貓開心跳起來：「認識一下，小笨貓。」接著蓋上「毒舌陪讀」印章 |
| 3.8–6.2s | 貼著膠帶的橫線索引卡（下面墊方格紙）：attend 看答案 → 翻面 → 點「認識」，小笨貓：「好喔，記住了。永遠。」 |
| 6.2–8.4s | 題目寫在撕邊方格紙上，選項是紙條：選錯「說法」，小笨貓：「蛤？你是來亂的嗎？」 |
| 8.4–10.3s | 拼貼版主卡（撕邊皮革、膠帶、網點），進度環 7／20，加上兩張練習方塊。小笨貓：「才 7 個？笑死。還差 13 個。」 |
| 10.3–12.0s | 拼貼版 icon 用膠帶貼上，出現「單字貓」，最後蓋上「7000 單字」印章 |
