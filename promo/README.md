# 單字貓（Word7000）宣傳短片

用 [Remotion](https://www.remotion.dev/) 寫成的直式（1080×1920、9:16）宣傳片，有兩個版本：

- `Full`：47.3 秒完整版，重點放在 AI 與客製化
- `Teaser`：18.7 秒試作版

兩支都以 1.2 倍慢速播放，輸出 60 fps，設定都在 `src/time.ts`：`SPEED` 控制速度，`OUTPUT_FPS` 控制輸出幀率。場景以 30 fps 的格數撰寫，`useFrame()` 會換算成放慢後、60 fps 的時間軸。剪接點、打字和動畫一起等比例變慢，同時多出中間格，所以動作更順。要改速度或幀率，只要改這兩個數字。

轉場參考 App 廣告的手法，不用硬切，而是依內容選擇（`src/transitions.tsx`）：
- 從小笨貓身上擴散的圓
- 帶動態模糊的推移
- 鏡頭推進穿過畫面
- 從「存入字庫」按鈕擴散的圓
- 往上推，像往下捲設定頁
- 從上方拉下的鎖定畫面
- 模糊淡出到片尾

AI 五段共用同一張桌面。「小笨貓會」固定不動，下一行在原地換成「講到你懂。→ 有問必答。→ 抓出錯在哪。→ 幫你改口說。→ 抓你的弱點。」，內容在下面橫向推移。

每一幕在動畫結束後多停 `HOLD` 格，再停到下一個強拍（`quantizeBeats`：每 2 拍，也就是小節的第 1 或第 3 拍）才轉場。轉場佔 1 拍（片尾 2 拍），兩幕在轉場期間重疊。表中的時間是該幕開始進場到完全離開。

## 配樂

`scripts/make-music.py` 會照 `src/timeline.json` 作出一首原創的 lo-fi 鋼琴曲，輸出到 `public/audio/full.mp3` 和 `teaser.mp3`。

- **速度與和聲**：每分鐘 90 拍，和弦是 Fmaj9 → Em7 → Dm9 → Cmaj9。
- **樂器**：柔和的毛氈鋼琴，聲音是程式合成的（每個音有略偏高的泛音、三條微微失準的弦、軟槌聲），彈和弦加上稀疏的旋律。
- **伴奏與質感**：圓潤的低音、放鬆的 boom-bap 鼓、搖擺的 hi-hat，再加上殘響、黑膠底噪和一點錄音帶晃動。

**換場就是節奏點。** 影片和配樂用同一套規則排時間，每次換場都從強拍開始，而且每次換場都會：
1. 換場前半拍，鼓全部停住。
2. 下一個和弦反轉過來往上湧，帶進換場。
3. 換場那一拍，大鼓加低頻重擊一起落下，鋼琴同時換成新和弦。

**段落安排**
- 開場：只有鋼琴，聲音像從隔壁房間傳來。
- 小笨貓登場：鼓和低音從重拍進來。
- 鎖定畫面：鼓退掉，只剩邊鼓和輕打。
- 片尾：一個慢慢分解開來的 Cmaj9 和弦，最後淡出。

推移、圓形擴散、蓋章、點按鈕和通知的音效都壓得很輕。

改了 `timeline.json` 裡的場景長度或轉場，就重新產生配樂，再輸出影片：

```bash
npm run music    # 需要 python3、numpy、scipy、ffmpeg
npm run render
```

## 使用方式

```bash
cd promo
npm install
npm run studio   # 在瀏覽器即時預覽、拖時間軸
npm run render           # 輸出 out/word7000-full-60fps.mp4
npm run render:teaser    # 輸出 out/word7000-teaser-60fps.mp4
npm run typecheck
```

在雲端容器或沒有下載 Chrome 的環境，可改用現有的 Chromium：

```bash
npx remotion render Full out/word7000-full-60fps.mp4 --browser-executable=/opt/pw-browsers/chromium
```

## 結構

- `src/Full.tsx`：30 秒版的場景；`src/Teaser.tsx`：10 秒版的場景，開場、認識小笨貓和片尾兩版共用。兩個檔案上方的 `SCENES` 都控制每一幕的起點與長度（30 fps）。
- `src/kit.tsx`：共用的動態效果（模糊浮現、紙片貼上、蓋章、打字機）和元件，例如小笨貓對話泡泡 `CatSays`、紙條按鈕。
- `src/collage.tsx`：App「紙張拼貼」風格的素材，從 `ios/Word7000/Design/Collage.swift`（`claude/friendly-darwin-obc3r1` 分支）移植而來，包括方格紙、橫線索引卡（含紅色邊線）、紙膠帶、撕邊、網點、炭筆線圈和橡皮章。這個風格沒有陰影，靠紙張彼此重疊做出層次。
- `src/Mascot.tsx`：吉祥物「小笨貓」，從 `Mascot.swift` 逐個形狀移植成 SVG。有 idle、smug、happy、annoyed 四種表情，也會呼吸、眨眼、甩尾巴。
- `src/fonts.ts`：中文用 Noto Sans TC，英文單字用 Noto Serif（代替 App 裡的 New York 襯線字）。文案有改時要更新裡面的字表。
- `public/icon-collage.png`：拼貼風格的 App icon。`public/icon.png` 是皮革風格的 icon，`public/paper-grain.png` 是紙張紋理。

尺寸換算是「App 的 pt × 1080/402」，也就是把 402pt 寬的 iPhone 放大到 1080px。小笨貓的台詞都是 App 裡實際會出現的句子。

## 分鏡（47.3 秒、71 拍，Full）

小笨貓就是 App 裡所有線上 AI 回答的化身，所以 AI 的段落都由牠來說。文案、按鈕和台詞都取自測試版。

| 時間 | 段落 | 畫面 |
| --- | --- | --- |
| 0.0–4.7s | 開場 | 「又在滑手機？」小笨貓：「你滑手機的時間夠背十個字了。」 |
| 4.0–7.3s | 開場 | 「認識一下，小笨貓。」嘴有點壞的 AI 單字家教，蓋「AI 家教」印章 |
| 6.7–12.7s | AI | 「不懂？叫牠講到懂。」點「叫小笨貓解說」，小笨貓說明 attend 的用法和常見搭配 |
| 12.0–16.7s | AI | 「想問什麼，直接問。」點預設問題「常見的錯誤用法是什麼？」：✗ attend to the meeting／✓ attend the meeting |
| 16.0–20.7s | AI | 「答錯了，牠說你錯在哪。」點「小笨貓，我為什麼錯？」 |
| 20.0–26.0s | AI | 「開口說，AI 幫你改。」口說教練：錄音後顯示文字，AI 給出更自然的說法和提示 |
| 25.3–30.0s | AI | 「每天一次，牠幫你抓弱點。」學習分析：做得好的地方、要加油的字、接下來幾天 |
| 29.3–34.0s | 掃描 | 「課本單字表，拍一下就好。」手寫單字表掃描後，由 Apple Intelligence 整理並存入字庫 |
| 33.3–38.0s | 客製化 | 「你的 App，你的樣子。」皮革經典切換成紙張拼貼，圖示跟著換 |
| 37.3–42.0s | 客製化 | 「每個設定，都照你的。」每日目標、學習語言、朗讀語速、單字集、學習提醒 |
| 41.3–45.3s | 提醒 | 鎖定畫面中午 12:00 的即時動態：「單字不會自己背好喔」。小笨貓：「明天同一時間，我會來找你。」 |
| 44.0–47.3s | 片尾 | 拼貼版 icon、「單字貓」、「7000 單字」印章 |
