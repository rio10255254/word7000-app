Word7000 Support

Need help with Word7000? This page covers sign-in, sync, updates, and account data requests.

Common checks

  • If sign-in does not return to the app, close the sign-in page and try again from Word7000.
  • If progress does not sync, sign out and sign in again with the same Google or Apple account.
  • If a web app update does not appear, use the update prompt or refresh the page.

Account data

Signed-in users can delete synced Word7000 learning data from the app settings screen.
